Graphing Sinusoids

Companion to Lesson 0003. Print it; keep it beside you while drilling. Grounded in Paul's Online Math Notes — Graphs of Trig Functions.

The standard form

y = A · sin(B(x − C)) + D   (or cos)

SymbolNameEffect on the graph
Aamplitude factoramplitude = |A|; if A < 0 the curve flips vertically
Bangular frequencyperiod = 2π/B; bigger B ⇒ shorter period
Cphase shiftshifts right if C > 0, left if C < 0 — after B is factored out
Dvertical shiftmidline is y = D

Read-off formulas

amplitude|A| = (max − min) / 2
midliney = D = (max + min) / 2
period2π / B
B from a known periodB = 2π / period
maximumD + |A|
minimumD − |A|
The two traps Period is 2π/B, never B.   Phase shift needs B factored out first: in sin(2x − π) factor to sin(2(x − π/2)), so the shift is π/2, not π.

Five-key-points method (to sketch one cycle)

  1. Draw the midline y = D and the max/min lines at D ± |A|.
  2. Start of cycle: x = C. Mark the four following points a quarter-period apart: C, C + T/4, C + T/2, C + 3T/4, C + T where T = 2π/B.
  3. For sin: the pattern across those five points is midline → max → midline → min → midline.
  4. For cos: max → midline → min → midline → max.
  5. If A < 0, flip the max/min roles.

Graph → equation reading order (Lesson 0006)

  1. Midline: D = (max + min)/2
  2. Amplitude: |A| = (max − min)/2
  3. Period → B = 2π/period
  4. Anchor a feature for phase and sign together: a max (cos anchor) or an upward midline crossing (sin anchor)
  5. Verify with one plug-in — distractors match three features; the plug-in kills them
Equivalent writings One curve, many equations: −sin x = sin(x − π), cos x = sin(x + π/2), and shifting any sinusoid by half its period equals reflecting it. Never read A's sign off the picture — anchor and check. A curve starting at a minimum is cleanest as a reflected cosine.

Which feature anchors which function

Step 4 is the one that decides phase and sign at once. Pick the feature that matches the function you intend to write.

At the anchor point the curve is at…Cleanest form
a maximum+cos
a minimum−cos
the midline, heading up+sin
the midline, heading down−sin

Cosine anchors peaks and troughs; sine anchors midline crossings. Choosing the wrong anchor type is what produces an answer that is right about amplitude, period and midline and still wrong.

How the distractors are built

Every wrong choice on a graph-matching question is constructed to agree with you on three of the four features. Reading features one at a time and stopping at the first match is exactly the behaviour being tested.

The distractorWhat it gets wrong
sin ↔ cos swappedanchor type — a peak read as a midline crossing
sign of A flippedthe reflection; matches everything else
phase left unfactoredcos(2x − π/6) shifts π/12, not π/6
phase off by a fraction of a periodright form, anchor in the wrong place
A and D swappedamplitude reported as the midline and vice versa
The plug-in habit Finish every graph-matching question by evaluating your equation at one labelled x-value and checking it against the picture. One failed plug-in is fatal — do not accept an equation because three other features agree. Three plug-ins a quarter period apart (min → midline → max) leave no distractor standing.

sin ⇄ cos

cos x = sin(x + π/2)cosine is sine shifted left by a quarter period
sin x = cos(x − π/2)sine is cosine shifted right by a quarter period

Sanity checks

The curve never leaves [D − |A|, D + |A|]an answer with points outside that band is wrong
Exactly one full cycle per 2π/Bif your sketch shows a different count, B is off
Amplitude is a distanceit is never negative — read |A|
