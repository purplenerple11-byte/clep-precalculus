Counting Trig Solutions

Companion to Lesson 0007. Print it. Grounded in Paul's Online Math Notes — Solving Trig Equations.

The substitution habit

  1. Name the inside: u = whatever sits inside the function (2x, 3x, 2x − π…).
  2. Stretch the window: x ∈ [0, 2π) and u = Bx ⇒ u ∈ [0, 2πB) — B full circles.
  3. Solve circle by circle: first-circle solutions, then +2π each per extra circle.
  4. Map back: divide every u by B (undo the full inner expression if it was Bx − φ).

Say it aloud Crossings twice per circle. Peaks once. Impossible never. Tangent: once per period, no exceptions.

When there is a phase shift inside

For sin(Bx − φ) = c, set u = Bx − φ. The shift moves the u-window without changing its length, so the count is unaffected — it is still B circles' worth.

x ∈ [0, 2π), u = 2x − π/3u ∈ [−π/3, 11π/3)length 4π — still two circles

Map back by undoing the whole inside, not just the B: x = (u + φ)/B. Dividing by B while forgetting the shift is the standard way this goes wrong.

When B is not a whole number

The 2B shortcut assumes u sweeps a whole number of circles. If B is fractional, drop the shortcut and count inside the actual window.

sin(x/2) = 1/2 on [0, 2π)u ∈ [0, π)half a circle — u = π/6, 5π/6, so 2 solutions
