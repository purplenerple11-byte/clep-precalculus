Inverse Trig & the Principal Range

sin⁻¹(sin 2π/3) is not 2π/3. Two worked examples, then thirty-four drills.

sin⁻¹ does not mean "undo the sine." It means: give me the one angle in [−π/2, π/2] whose sine is this value. Sine hits every value infinitely often, and a function may return only one answer — so each inverse commits to a fixed window, its principal range. Every question in this lesson is asking the same thing: which angle inside the window?

FunctionPrincipal rangeQuadrantsA negative input lands…

All three contain QI, so positive inputs are just the special-angle values you already know. The whole game is negative inputs, and there the three split: arcsin and arctan answer with a negative angle; arccos answers in the second quadrant. That asymmetry is where every trap in this topic lives.
